# 🚀 Kapten Nemo Personal Hub

Sebuah *landing page* personal dan alternatif Linktree yang didesain secara khusus menggunakan gaya **Dark Glassmorphism**. Halaman ini berfungsi sebagai kartu nama digital untuk memberikan akses cepat ke CV dan berbagai platform media sosial saya.

## 🎨 Fitur Utama
- **Desain Modern:** Menggunakan efek *frosted glass* ala iOS.
- **High Contrast:** Tema hitam pekat dengan aksen merah minimalis.
- **Responsif:** Mobile-first design yang tampil sempurna di layar *smartphone* maupun *desktop*.
- **Akses Cepat:** Tombol utama untuk mengunduh/melihat CV dan mengunjungi profil lengkap.

## 🛠️ Teknologi yang Digunakan
- HTML5 / CSS3
- [Tailwind CSS](https://tailwindcss.com/) (untuk penataan gaya dan efek *backdrop-blur*)
