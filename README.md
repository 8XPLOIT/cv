# 🚀 Kapten Nemo Personal Hub

Sebuah *landing page* personal dan alternatif Linktree yang didesain secara khusus menggunakan gaya **Dark Glassmorphism**. Halaman ini berfungsi sebagai kartu nama digital untuk memberikan akses cepat ke CV dan berbagai platform media sosial saya.

## 🎨 Fitur Utama
- **Desain Modern:** Menggunakan efek *frosted glass* ala iOS.
- **High Contrast:** Tema hitam pekat dengan aksen merah minimalis.
- **Responsif:** Mobile-first design yang tampil sempurna di layar *smartphone* maupun *desktop*.
- **Akses Cepat:** Tombol utama untuk mengunduh/melihat CV dan mengunjungi profil lengkap.

## ✨ Fitur Utama

- **Premium UI/UX:** Desain *frosted glass* (kaca buram) transparan di atas latar belakang hitam pekat dengan aksen merah minimalis yang memukau.
- **Mobile-First Design:** Tata letak satu kolom yang dioptimalkan dengan sempurna untuk tampilan *smartphone* maupun *desktop*.
- **High-Contrast Call-to-Action:** Tombol interaktif untuk akses instan ke **Curriculum Vitae (CV)** dan **Link Bio** utama.
- **Performa Ringan:** Dibangun menggunakan HTML statis dan *styling* utilitas untuk *loading* yang secepat kilat.


## 🛠️ Teknologi yang Digunakan
- HTML5 / CSS3 (single-file `index.html`)


---

## 🛠️ Teknologi yang Digunakan

*   **HTML5** - Struktur semantik halaman.
*   **CSS3** - Animasi *ambient glow* dan efek visual.
*   **Tailwind CSS** - *Framework utility-first* untuk menciptakan efek *backdrop-blur*, tata letak responsif, dan tipografi modern secara efisien.
-   [Tailwind CSS](https://tailwindcss.com/) via CDN
-   **Dark / Light** theme toggle dengan persistensi `localStorage`
